# team-docs-AA

# Наш DevOps проект

## Описание проекта
Учебный проект для практики командной работы с Git и GitHub: ветвление, Pull Request, разрешение merge-конфликтов.

## Команда
- Кадыркулова Амина
- Базарбеков Алмазбек 

## Стек технологий
- Docker
- Linux
- Git / GitHub

## Инструкции по запуску
1. Клонировать репозиторий: `git clone https://github.com/chaoryy/team-docs-AA`
2. Перейти в папку проекта: `cd team-docs-AA`
3. Запустить проект: `docker-compose up`
